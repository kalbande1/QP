CSV द्वारे मराठी प्रश्न अपलोड करा

तयार CSV फाईल निवडून सेकंदात संपूर्ण प्रश्नपत्रिका अपलोड करा.

मराठी फॉन्ट व CSV सेव्ह करण्याविषयी महत्त्वाची सूचना:
  • मराठी टाईपिंगसाठी युनिकोड (Devanagari Unicode / Mangal Font) वापरा.
  • Microsoft Excel मध्ये फाईल सेव्ह करताना 'CSV UTF-8 (Comma delimited) (*.csv)' हाच फॉरमॅट निवडा.
  • Google Sheets वापरत असल्यास File -> Download -> Comma-separated values (.csv) डाऊनलोड करा.
  • कॉलम नावे: subject, question_text, option_a, option_b, option_c, option_d, correct_option, explanation, image_url
